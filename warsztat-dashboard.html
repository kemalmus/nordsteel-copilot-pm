Otwórz dashboard

Otwórz dashboard ↗Pobierz HTML
  1. Napisz polecenie, w którym Copilot wypisze z notatki z kickoffu zadania bez właściciela lub terminu. Porównaj wynik z notatką. Czy Copilot nie dopisał osoby albo daty, których tam nie ma?
  2. Dodaj w dashboardzie jedno takie zadanie. W polu, którego brakuje, wpisz „do ustalenia”.
  3. Użyj „Zapisz projekt”, otwórz pobraną kopię i sprawdź wpis. Gdy zapis jest zablokowany, odnotuj wynik testu i zapisz aktualizacje w notatkach poniżej.
  4. Zrób test „pierwszego spojrzenia”: zamknij plik, otwórz zapisaną kopię i w 30 sekund odpowiedz sobie, co wymaga decyzji, kto za to odpowiada i skąd są dane. Jeśli coś zajęło więcej czasu, zapisz jedną poprawkę.
Podpowiedź · otwórz, jeśli utkniesz
Dołącz notatkę z kickoffu.
Z dołączonej notatki ze spotkania wypisz wszystkie zadania do wykonania (action items). Dla każdego podaj właściciela i termin dokładnie tak, jak są zapisane w notatce. Jeśli czegoś brakuje albo termin jest nieprecyzyjny, napisz „brak w notatce” lub zacytuj oryginalne sformułowanie. Nie uzupełniaj braków domysłami.
Dla szybszych · wygeneruj własny dashboard

Zbuduj własną wersję z Copilotem. Wklej notatkę z kickoffu i swoje ustalenia w miejsce oznaczone nawiasami. Działający plik zwykle wymaga 2–3 poprawek. Jeśli nie zdążysz, dokończ po szkoleniu.

Prompt · dashboard statusu projektu
Prompt
Napisz jeden samodzielny plik HTML (czysty HTML5, CSS i JavaScript w środku tego samego pliku, ŻADNYCH bibliotek ani plików zewnętrznych, ma działać po otwarciu z dysku bez internetu) — dashboard statusu projektu „Baza wiedzy Nordsteel". Poniżej wklejam dane projektu; wpisz je do pliku.

Wymagania:
- Nagłówek z nazwą projektu, datą i dużym wskaźnikiem statusu (zielony/żółty/czerwony) — kolory jako zmienne CSS.
- Pasek postępu ogólnego (element progress) oraz oś kamieni milowych z datami i statusem każdego.
- Liczniki: ryzyka, założenia, problemy, zależności (RAID) — mają się przeliczać z danych w pliku.
- Top 5 ryzyk (sortowane wg prawdopodobieństwo × wpływ); kliknięcie ryzyka otwiera okno szczegółów (element dialog).
- Otwarte decyzje oraz tabela działań (opis, właściciel, termin, status: Do zrobienia / W toku / Zrobione), z możliwością dodania wiersza i edycji komórek bezpośrednio w tabeli.
- Zwijane sekcje (element details). Układ CSS Grid, który nie rozjeżdża się po dodaniu wiersza.
- Przycisk „💾 Zapisz projekt": pobiera świeżą kopię tego samego pliku HTML z aktualnymi danymi i moimi edycjami w środku (użyj Blob i atrybutu download). NIE używaj localStorage jako źródła danych.
- Przycisk „🖨 Drukuj / PDF" oraz reguły @media print dające czysty jednostronicowy status.
- Duże czcionki (min 16 px, nagłówki min 24 px), wysoki kontrast, czytelne przy udostępnianiu ekranu; działa też na wąskim ekranie.
- Na górze pliku komentarz: nazwa aplikacji, wersja (baseline), jak zapisać (przycisk Zapisz projekt), jak zaktualizować przez Copilota (wkleić nowe informacje i poprosić o nową wersję pliku).
- Interfejs po polsku. W interfejsie nie używaj żargonu technicznego. Kod prosty i czytelny, żebym mógł go potem poprosić o zmiany. Oddaj cały plik w jednym pliku html, ktory moge sciagnac.
